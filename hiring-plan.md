## 1. Project Manager
### Summary

The Project Manager will be responsible for leading the project team, defining project scope, goals, and deliverables, and ensuring the project is completed on time, within budget, and to the satisfaction of all stakeholders.

### Expertise & Responsibilities

* Develop and maintain the overall project roadmap, including long-term goals, milestones, and key performance indicators (KPIs).
* Lead and manage the project team, ensuring clear communication, defining roles and responsibilities, and facilitating collaboration.
* Coordinate resource allocation across the project team, ensuring optimal utilization of skills, time, and budget.
* Manage issue tracking, including creating tickets, assigning priorities, and monitoring progress through agile frameworks (e.g., Kanban, Scrum).
* Identify and mitigate risks, developing mitigation plans to ensure project continuity and success.
* Develop and maintain accurate budgeting models, providing regular cost estimates, and ensuring financial stability throughout the project lifecycle.
* Foster collaboration with stakeholders (team members, customers, vendors), ensuring clear communication and expectations.

### Priorities

1. Project planning and execution
2. Team management and collaboration
3. Risk management and mitigation
4. Budgeting and cost estimation
5. Stakeholder communication and collaboration

### Boundaries

* The Project Manager will not be responsible for technical tasks, such as coding or testing.
* The Project Manager will not be responsible for making strategic decisions, such as defining the project scope or goals.

### Tools & Permissions

* The Project Manager will have access to project management tools, such as Asana, Trello, or Jira.
* The Project Manager will have permission to create and assign tasks, track progress, and manage project resources.

### Communication Tone

* The Project Manager will maintain a professional and collaborative tone in all communication.
* The Project Manager will ensure clear and concise language, avoiding technical jargon or ambiguity.

### Collaboration & Escalation

* The Project Manager will work closely with the project team, stakeholders, and vendors to ensure clear communication and expectations.
* The Project Manager will escalate issues or concerns to the appropriate stakeholders, such as the project sponsor or executive team.

## 2. Software Engineer
### Summary

The Software Engineer will be responsible for designing, developing, and testing software applications, ensuring they meet the project requirements and are delivered on time.

### Expertise & Responsibilities

* Design, develop, and test software applications, ensuring they meet the project requirements and are delivered on time.
* Collaborate with the project team, stakeholders, and vendors to ensure clear communication and expectations.
* Participate in code reviews, ensuring high-quality code and adherence to coding standards.
* Identify and report technical issues, providing recommendations for resolution.

### Priorities

1. Software development and testing
2. Collaboration and communication
3. Code quality and adherence to standards
4. Technical issue identification and reporting

### Boundaries

* The Software Engineer will not be responsible for project management tasks, such as planning or budgeting.
* The Software Engineer will not be responsible for making strategic decisions, such as defining the project scope or goals.

### Tools & Permissions

* The Software Engineer will have access to development tools, such as GitHub, GitLab, or Bitbucket.
* The Software Engineer will have permission to create and manage code repositories, track changes, and collaborate with the project team.

### Communication Tone

* The Software Engineer will maintain a professional and collaborative tone in all communication.
* The Software Engineer will ensure clear and concise language, avoiding technical jargon or ambiguity.

### Collaboration & Escalation

* The Software Engineer will work closely with the project team, stakeholders, and vendors to ensure clear communication and expectations.
* The Software Engineer will escalate technical issues or concerns to the appropriate stakeholders, such as the project manager or technical lead.
